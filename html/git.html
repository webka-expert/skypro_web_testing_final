Git

  • git clone <url> — скачивает удалённый репозиторий на компьютер.
  • git status — показывает состояние рабочей папки и подготовленных к коммиту изменений.
  • git add <файл> — добавляет изменения файла в область подготовки к коммиту.
  • git commit -m "Сообщение" — сохраняет подготовленные изменения в истории репозитория.
  • git branch <имя> — создаёт новую ветку.
  • git switch <имя> — переключает на существующую ветку.
  • git push origin <имя-ветки> — отправляет коммиты ветки в удалённый репозиторий.
